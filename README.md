## 🚀 Featured Project

### [T.L.S — Sign Language Translator](https://github.com/Santouc/MIMOAPP)
A real-time desktop application that translates sign language into text and speech using computer vision and machine learning.

- 🖐️ Hand tracking with **MediaPipe** (21 keypoints)
- 🧠 Custom **TensorFlow** models for static & dynamic gesture classification, preserving motion trajectory
- 💬 Offline **NLP engine** (Viterbi segmentation + lexical frequency) to reconstruct coherent phrases without paid APIs
- 🔌 Plugin/extension system for runtime-loadable features (e.g. automatic text-to-speech)
- 🎓 Built-in training module — teach the app new signs directly from the camera

**Stack:** Python · PySide6 · MediaPipe · TensorFlow · OpenCV
